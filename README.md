# 🎭 Rol Oyunu Karakter Takipçisi

Yapay zeka destekli, GTA V ve Red Dead Redemption 2 roleplay karakterlerinizi takip etmek ve geliştirmek için tasarlanmış web uygulaması.

![Version](https://img.shields.io/badge/version-1.3-blue)
![AI](https://img.shields.io/badge/AI-Google%20Gemini-orange)

## ✨ Özellikler

### 🎯 Karakter Yönetimi
- **Çoklu Karakter Desteği**: Sınırsız karakter oluşturun ve yönetin
- **İki Oyun Türü**: GTA V (Los Santos) ve RDR2 (Old West) desteği
- **Detaylı Profiller**: Hikaye, özellikler, yetenekler ve RP bilgileri
- **Karakter Teması**: Her karakter için özel renk paleti

### 📖 Günlük Sistemi
- **Takvim Görünümü**: Ay bazında görsel günlük takibi
- **Markdown Desteği**: Zengin metin formatlaması
- **AI İyileştirme**: Günlük girişlerinizi karakterin sesiyle yeniden yazın
- **Otomatik Özet**: Uzun girişler için kısa özetler oluşturun
- **Tema Entegrasyonu**: Günlük takvimi karakter temanızı kullanır

### ⏱️ Zaman Çizelgesi
- **Olay Takibi**: Önemli olayları kategorize edin (Suç, İlişki, İş, Kişisel)
- **AI Önerileri**: Günlük girişlerinizden otomatik olay tespiti
- **Filtreleme**: Olay tipine göre filtreleme
- **Görsel Timeline**: Kronolojik olay görüntüleme

### 🤖 Yapay Zeka Özellikleri
- **Kişilik Analizi**: Eleştirel karakter değerlendirmesi
- **Gerçekçilik Kontrolü**: 0-100 puan sistemi ile detaylı analiz
- **Karakter Sohbeti**: İki modlu Q&A (Karakter olarak / Karakter hakkında)
- **Senaryo Planlayıcı**: Durum analizi ve karakter tepki tahmini
- **Tema Önerisi**: Kişiliğe uygun renk paleti önerileri
- **Genel Durum**: Otomatik karakter durumu özeti

### 🎨 Özelleştirme
- **Karakter Temaları**: AI destekli veya manuel renk seçimi
- **Açık/Koyu Mod**: Göz dostu tema seçenekleri
- **Responsive Tasarım**: Mobil ve masaüstü uyumlu
- **Markdown Desteği**: Tüm metin alanlarında zengin formatlar

### 💾 Veri Yönetimi
- **Yerel Depolama**: Tüm veriler tarayıcınızda güvenle saklanır
- **Import/Export**: JSON formatında yedekleme
- **Otomatik Kayıt**: 30 saniyede bir otomatik kaydetme
- **Gizlilik**: Hiçbir veri sunucuya gönderilmez

## 🚀 Hızlı Başlangıç

### Kurulum

1. **Dosyaları İndirin**
   ```bash
   git clone https://github.com/zy9pix/RP-Character-Tracker.git
   cd roleplay-character-tracker
   ```

2. **Uygulamayı Açın**
   - `index.html` dosyasını tarayıcınızda açın
   - Veya bir web sunucusunda host edin

3. **API Anahtarı Ekleyin** (İsteğe Bağlı - AI özellikleri için)
   - [Google AI Studio](https://makersuite.google.com/app/apikey) üzerinden ücretsiz API anahtarı alın
   - Ayarlar (⚙️) → API Ayarları → Gemini API Anahtarı
   - Anahtarınızı yapıştırın ve kaydedin

### İlk Karakterinizi Oluşturun

1. "İlk Karakterinizi Oluşturun" butonuna tıklayın
2. Oyun türünü seçin (🚗 GTA V veya 🤠 RDR2)
3. Karakter adını girin
4. "Oluştur" butonuna tıklayın

## 📚 Kullanım

- **Hikaye**: Karakterinizin geçmişini yazın
- **Özellikler**: Kişilik, fiziksel ve davranış özellikleri ekleyin

### RP Bilgileri
- **Geçmiş & Köken**: Nereden geldi, neden buraya geldi
- **Genel Durum**: Karakterin şu anki durumu
- **Tanıdık Kişiler**: İlişkileri ve iletişim takibi
- **Senaryo Planlayıcı**: "Ne olursa ne olur" senaryoları

### Yetenekler
- Karakterinizin özel yeteneklerini ekleyin
- 1-10 arası seviye sistemi
- Detaylı açıklamalar

### Günlük
- Takvim görünümünde günlük girişleri
- Markdown ile zengin formatlar
- AI ile iyileştirme ve özet oluşturma
- Tarih bazlı filtreleme

### Zaman Çizelgesi
- Önemli olayları kaydedin
- AI ile otomatik olay tespiti
- Tip bazlı filtreleme
- Kronolojik görüntüleme
